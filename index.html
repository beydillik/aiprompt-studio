About

Turn a rough note into a clear AI prompt

AI Prompt Studio takes the text you would normally paste into a chat window, adds the instructions an assistant needs (task, tone, length, output language) and hands it to the assistant you choose.

It does not call any AI itself and has no server. You can write in one language and ask for the result in another: the interface language and the output language are set separately.

How it works

  1. 1Pick a toolRephrase, Summarise, Reply, Create e-mail, Translate or General prompt.
  2. 2Write your notePaste or type it as it is. Choose tone, length, complexity, style and the output language.
  3. 3Send itChatGPT, Claude and Perplexity open with the prompt filled in. For Gemini, Copilot, Grok, Mistral, DeepSeek, Qwen and Kimi it is copied, ready to paste.

Privacy

  • No account and no sign-up.
  • Your notes, settings and prompt history are kept in this browser's local storage, not on a server.
  • Your text leaves the page only when you send it to an AI tool yourself.
  • Visits are counted with a cookie-free analytics script.

Questions

Is it free?

Yes. All six tools and all nine languages, with no sign-up and no key.

Why not just type into ChatGPT or Claude?

You can. The tool helps when you want the same structure every time: tone, length and output language set in two clicks, and a prompt you can check and edit before sending.

Which languages are supported?

English, Turkish, German, French, Russian, Spanish, Portuguese, Chinese and Japanese, for both the interface and the output.

Does it work on a phone?

Yes. The send and copy buttons stay at the bottom of the screen.

How is it built?

It is one static HTML file: no framework, no build step, no backend. It started as an Excel/VBA tool.
